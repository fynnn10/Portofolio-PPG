01 • Modul Ajar

Praktik Pengenalan Software & Pengelolaan File

Modul Ajar Siklus 4 berfokus pada pengenalan perangkat lunak (*software*) dengan menerapkan model Discovery Learning dan pendekatan mendalam (*Deep Learning*). Pembelajaran dirancang agar siswa mampu memahami peran krusial software sebagai "jiwa" yang menghidupkan perangkat keras (*hardware*)[cite: 42, 45].

  • Tujuan Pembelajaran: Siswa mampu menjelaskan pengertian software, membedakan peran Sistem Operasi ("Sang Manajer") dengan Program Aplikasi ("Pekerja Spesialis"), mengidentifikasi versi sistem operasi, serta mempraktikkan pembuatan dan penyimpanan dokumen pada folder kerja di laboratorium[cite: 41, 42, 45].
  • Etika & Aturan Lab: Menekankan kedisiplinan siswa untuk tidak mengubah pengaturan sistem, tidak menghapus/memasang aplikasi tanpa izin guru, serta menjaga keamanan data pada penyimpanan (*storage*)[cite: 45].
  • Penguatan Profil Pelajar Pancasila: Membangun dimensi bernalar kritis, mandiri, gotong royong, dan kreatif melalui kerja berpasangan di laboratorium komputer[cite: 45].

02 • Media Pembelajaran

Media Interaktif Visualisasi Ekosistem Komputer (PPT)

Media pembelajaran dikemas secara visual dan komunikatif guna memperjelas konsep abstrak perangkat lunak:

  • Analogi Lapisan Ekosistem (Layering): Menggunakan ilustrasi visual 4 lapis (Pengguna → Program Aplikasi → Sistem Operasi → Hardware) untuk menunjukkan bahwa seluruh lapisan harus saling terhubung agar komputer berfungsi normal[cite: 42].
  • Matriks Perbandingan & Misi Lab: Menampilkan tabel perbedaan fungsi antara Sistem Operasi dan Program Aplikasi, serta infografis 4 langkah misi penjelajahan lab (Identifikasi, Eksplorasi, Aksi, dan Aturan Emas)[cite: 42].

03 • Lembar Kerja (LKPD)

Eksplorasi Sistem Operasi & Praktik Aplikasi

LKPD Siklus 4 dirancang sebagai panduan kerja investigatif dan praktis bagi peserta didik:

  • Aktivitas Identifikasi & Klasifikasi: Siswa mengamati logo/ikon software, menuliskan fungsinya (Windows, Chrome, MS Word, Excel, Photoshop, dll), serta mengelompokkannya ke dalam kategori Sistem Operasi atau Program Aplikasi[cite: 41].
  • Praktik Lapangan Terstruktur: Memandu siswa membuka menu Start, mengeksplorasi fitur sistem operasi, membuka aplikasi pengolah kata, mengetik teks uji coba ("Saya Suka Informatika"), serta menyimpan file ke dalam folder kerja pribadi[cite: 41].
